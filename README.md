# -An-Adjustable-Vector-Topology-Analysis-Method-for-the-Magnetic-Gradient-Tensor-Field
The verifiable program of the paper "An Adjustable Vector Topology Analysis Method for the Magnetic Gradient Tensor Field"
Each folder corresponds to one picture.
For example, when reproducing Fig. 4, all the files in Fig. 4 (whether they are .mat files or .m files) should be placed in a single folder. Do not include files from other folders such as Fig. 5 in this folder. Then, run the .m files with the suffix "__main" or "_draw".
## Requirements

The code has been tested with MATLAB R2020b.
